第二块：Dataset & Sampler（zarr → 训练样本 batch）

    这一块是“你同学改单手单臂”的核心：action 7/81 → 10/84、rotvec→rot6d、relative/delta 表示。
    这一块你要搞清楚
    SequenceSampler 采样出来的 data 里面，obs/action 的 raw 形状是什么
    UmiDataset.__getitem__ 最终输出的：
    batch['obs'][key] 的 shape
    batch['action'] 的 shape（应该是 (action_horizon, 84) 单臂）
    action 的语义到底是什么：预测未来的 “pose相对量 + hand_nodes绝对值/增量”

第三块：Training Workspace & Policy（batch → loss → ckpt）

    这一块通常不需要大改，除非有写死 10D 的地方（你已经在 log_action_mse 修过一次）。
    这一块你要搞清楚
    policy 是怎么从 shape_meta 推断 action_dim / obs keys 的
    workspace 里有没有任何地方写死 action_dim=10（除了日志，还有 env_runner / rollout / 保存可视化）
    训练时 normalizer 是怎么计算、存、加载、应用的（确保 hand_nodes 进入 normalizer）

    A. Workspace（训练编排器）

        所以真正训练入口是：

diffusion_policy/workspace/train_diffusion_unet_image_workspace.py

        类：TrainDiffusionUnetImageWorkspace
        看它的 __init__() 和 run() 就能看到：dataset/dataloader/normalizer/model/optimizer/loop/ckpt。

        2.1 初始化 accelerate + wandb
            accelerator = Accelerator(log_with='wandb')
            accelerator.init_trackers(...)

            注意：你 yaml 里 logging.mode: online，所以没登录 wandb 会出问题；离线就改成 offline。

        2.3 instantiate dataset（这里开始真正读你生成的 zarr）
            dataset = hydra.utils.instantiate(cfg.task.dataset)
            train_dataloader = DataLoader(dataset, **cfg.dataloader)

            这里的 cfg.task.dataset 来自 task/hand_umi.yaml，通常类似：
            _target_: diffusion_policy.dataset.umi_dataset.UmiDataset
            dataset_path: hand_umi_dataset/dataset.zarr.zip
            shape_meta: ...
            ✅ 结论：zarr 的读取、样本切片、rot6d/relative 等所有“数据处理”，都不在 workspace，而在 dataset 类里。
                                    
        2.4 计算 normalizer（这一步很关键）
            if accelerator.is_main_process:
                normalizer = dataset.get_normalizer()
                pickle.dump(normalizer, open(normalizer_path,'wb'))
            accelerator.wait_for_everyone()
            normalizer = pickle.load(...)

            含义：

            只在主进程扫描一遍 dataset，统计 obs/action 分布

            保存到 output_dir/normalizer.pkl

            所有进程加载同一份 normalizer

            ✅ 你以后改 obs/action 维度（比如改成“手指角度”），dataset.get_normalizer() 一定要同步支持，否则会报 unsupported 或 shape mismatch。              
                                    
        2.8 env_runner（rollout）
            env_runner = hydra.utils.instantiate(cfg.task.env_runner, output_dir=...)

            ⚠️ 你 hand_umi 如果没有对应环境，这里可能：

            直接跑不通（action_dim 不匹配）

            或者 runner 逻辑无意义

            实操建议：如果你现在只是离线 BC 训练、没有 rollout 环境：

            把 rollout_every 设很大（比如 999999）

            或者在 task/hand_umi.yaml 里用一个 dummy runner（如果 repo 有）

inspire 双手双臂流程
0. 开conda环境

1. npz生成zarr。
齐次变换矩阵
    → 提取平移部分 xyz
    → 提取旋转矩阵 R
    → scipy Rotation.as_rotvec()
    → 得到 axis-angle / rotation vector
    actual_ee_pose_left:  (T, 4, 4) float32
        → 拆成
    robot0_eef_pos:       (T, 3) float32
    robot0_eef_rot_axis_angle: (T, 3) float32

    actual_ee_pose_right: (T, 4, 4) float32
        → 拆成
    robot1_eef_pos:       (T, 3) float32
    robot1_eef_rot_axis_angle: (T, 3) float32

object dict
    → 取出 frame["angles"]
    → 检查 shape == (6,)
    → stack 成二维数组
    angle_left: object array, length T
        每帧 dict: {"angles": shape (6,)}
        → robot0_hand_angles: (T, 6) int32

    angle_right: object array, length T
        每帧 dict: {"angles": shape (6,)}
        → robot1_hand_angles: (T, 6) int32

compressed image bytes
    → cv2.imdecode()
    → BGR 转 RGB
    → resize 到 224x224
    → 用 JPEG-XL compressor 写入 zarr
    rgb3: object array, length T
        每帧 dict: {"format": ..., "data": compressed bytes}
        → camera0_rgb: (N, 224, 224, 3) uint8

    rgb2: object array, length T
        → camera1_rgb: (N, 224, 224, 3) uint8

    kinect_rgb: object array, length T
        → camera2_rgb: (N, 224, 224, 3) uint8

pose6[0] / pose6[-1]
    → repeat T 次
    每个 episode 的第一帧 pose
        → robot0_demo_start_pose: (T, 6) float32
        → robot1_demo_start_pose: (T, 6) float32

    每个 episode 的最后一帧 pose
        → robot0_demo_end_pose: (T, 6) float32
        → robot1_demo_end_pose: (T, 6) float32

2. train 入口
 train_diffusion_unet_timm_umi_workspace.yaml
 python train.py --config-name=train_diffusion_unet_timm_umi_workspace task.dataset_path=hand_inspire_dataset/dataset.zarr.zip
